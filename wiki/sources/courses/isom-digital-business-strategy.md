## 概述

ISOM3000E 數字商業策略：駕馭平台、群眾與機器為工商管理三年級學生探討平台經濟、群眾智慧及人工智能如何從根本上重塑競爭優勢與行業邊界，以 Parker、Van Alstyne 與 Choudary《平台革命》（Platform Revolution，Norton）為核心教材，先修要求為 ISOM2400 電子商務及 ISOM2700 運營管理。課程以管道型商業（線性價值鏈）對比平台型商業（多邊市場協調）的框架為分析基礎，深入剖析直接網絡效應與交叉網絡效應的強度差異、平台達到臨界規模的啟動策略（補貼策略、單人模式價值、明星用戶招募），以及平台架構的開放性決策（API 設計、第三方開發者治理）。案例橫跨西方平台（Uber、Airbnb、Amazon Marketplace、Facebook）與中國平台生態（微信超級應用、阿里巴巴生態圈、美團的本地生活服務）。人工智能模塊分析算法推薦（協同過濾）、動態定價（Uber 激增定價）及機器學習在欺詐檢測與內容審核中的應用。學生完成課程後能夠診斷平台商業模式的網絡效應結構、設計平台啟動的雙邊市場策略，以及評估數字化轉型對傳統行業（物流、零售、金融）的顛覆路徑，是管理諮詢與科技創業方向的重要策略思維培訓。

## Course Overview

**Primary Text**: Parker, Van Alstyne & Choudary, *Platform Revolution: How Networked Markets Are Transforming the Economy*

Elective course examining how digital platforms create value and competitive moats through network effects, algorithmic amplification, and crowd participation.

## Key Topics

### Platform Fundamentals
- **Pipeline vs. Platform businesses**: pipelines create value through linear transformation; platforms orchestrate interactions between multiple user groups
- **Multi-sided markets**: platforms serve two or more distinct user groups; e.g., Airbnb serves hosts and guests
- Value creation: core interactions; ensuring quality; reducing friction

### Network Effects
- **Direct (same-side) network effects**: each new user makes the platform more valuable for existing users (e.g., WhatsApp, fax machines)
- **Indirect (cross-side) network effects**: growth on one side benefits the other side (e.g., more sellers attract buyers; more buyers attract sellers)
- Network effect strength: local vs. global; homogeneous vs. heterogeneous networks
- **Critical mass**: minimum viable scale for network effects to kick in; strategies to achieve it (subsidy one side, seed content)
- Multi-homing: users on multiple platforms; implications for winner-take-all dynamics

### Platform Architecture
- **Modular architecture**: core vs. periphery; APIs as integration layer
- **Openness decisions**: open vs. closed; governance of third-party developers
- **Platform envelopment**: incumbents bundle new services to kill adjacent platforms
- Interface design for interaction quality; curation vs. openness trade-off

### Platform Launch and Scaling
- Chicken-and-egg problem: strategies for simultaneous two-sided launch
- Seeding strategies: start with one side; single-player mode value; marquee users
- Viral growth: referral programs; social sharing mechanics; viral coefficient $k = i \times c$

### Crowd and User-Generated Content
- Wisdom of crowds: prediction markets; open-source; crowdsourcing
- Quality curation: reputation systems, ratings, algorithmic filtering
- Wikipedia and Linux as canonical crowd production examples

### Machine and AI in Platforms
- Algorithmic recommendation: matching users to content/products — see [[recommendation-systems]]
- Dynamic pricing: surge pricing (Uber); yield management — see [[revenue-management]]
- Machine learning for fraud detection, content moderation, personalization — see [[machine-learning-advanced]]

### Platform Strategy and Competition
- Winner-take-all vs. winner-take-most dynamics: when platforms co-exist
- Regulatory and antitrust issues: GDPR, app store fees, data portability
- Chinese platform ecosystem: WeChat (super-app), Alibaba, Meituan; differences from Western platforms
