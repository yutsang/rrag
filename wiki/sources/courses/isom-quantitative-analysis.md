## 概述

ISOM1500 商業數量分析為工商管理學院一年級學生提供統計學與決策分析的應用入門訓練，無特定先修要求，著重實際商業場景而非數學推導，是 ISOM2500 商業統計及所有 ISOM 高年級分析課程的統計學先修科目。課程以 Excel（Data Analysis ToolPak）為主要計算工具，涵蓋描述統計（集中趨勢、離散程度、偏態）、概率基礎（條件概率、Bayes 定理、二項與正態分佈）、抽樣分佈與中央極限定理、單樣本與雙樣本假設檢定（z-test、t-test、卡方獨立性檢定）、單因子 ANOVA，以及簡單與多元線性回歸分析。決策分析模塊引入支付矩陣（maximax、maximin、期望值準則）與決策樹的逆向推導（rollback 法），並介紹完美信息期望值（EVPI）的計算，為管理決策提供系統化的量化框架。學生完成課程後能夠使用 Excel 進行迴歸分析與假設檢定、解讀 p 值與信賴區間的實際含義，以及在不確定性下構建決策樹並比較方案的期望值，直接支撐行銷分析、財務預測及運營績效評估等商業應用。

## Key Topics

### Descriptive Statistics
- Measures of central tendency: mean, median, mode; weighted average
- Measures of dispersion: variance, standard deviation, range, IQR; coefficient of variation
- Shape: skewness, kurtosis; identifying outliers with box plots
- Frequency distributions; histograms; ogives

### Probability
- Sample spaces, events; complement, union, intersection
- Addition rule; multiplication rule; conditional probability
- Independence; Bayes' theorem (applied)
- Key distributions: Binomial (n, p); Poisson (λ); Normal ($\mu$, $\sigma$)

### Sampling Distributions and Estimation
- Sampling distribution of the mean; CLT application
- Confidence intervals for mean (z and t); for proportion
- Sample size determination

### Hypothesis Testing
- Null and alternative hypotheses; Type I and Type II errors
- z-test and t-test for one and two means
- Chi-square test for independence; goodness of fit
- ANOVA: one-way; F-statistic interpretation — see [[hypothesis-testing]]

### Regression Analysis
- Simple linear regression: OLS; interpretation of slope and intercept
- Coefficient of determination $R^2$; standard error of estimate
- Inference: t-test for slope; F-test for model significance
- Multiple regression intro: multiple predictors; adjusted $R^2$; multicollinearity warning
- See [[linear-regression]]

### Decision Analysis
- Decision tables: payoff matrix; maximax, maximin, minimax regret, expected value
- Decision trees: rollback method; EVPI (expected value of perfect information)
- See [[decision-trees]]

## Tools
- Heavy use of Microsoft Excel: Data Analysis ToolPak for regression and ANOVA
- Excel functions: NORM.DIST, T.DIST, CHIINV, CORREL, LINEST
