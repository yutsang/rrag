## 概述

ISOM2010 電腦與商業應用為商學院二年級學生提供主流辦公室生產力工具與信息系統基礎知識的實操訓練，無特定先修要求，以 Microsoft Office Suite（Excel、Access、PowerPoint）為核心教學平台，由 Dongwon Lee 等教師主持。課程以商業情境項目為驅動，涵蓋 Excel 的進階公式（VLOOKUP、INDEX/MATCH、陣列函數）、樞紐分析表與樞紐圖、Solver 加載項（線性規劃問題的電子表格建模）、Data Analysis ToolPak（描述統計、迴歸、t 檢定），以及 Access 資料庫的關聯表設計、SQL 查詢基礎和表單報表製作。信息系統理論部分介紹 MIS 的三種類型（TPS、DSS、EIS）、ERP 系統的模組整合邏輯（SAP 概念）、CRM 的客戶數據管理及雲端運算（SaaS/PaaS/IaaS）的商業含義。數據可視化與 PowerPoint 模塊強調有效圖表設計原則（最小化圖表雜訊、選擇合適圖表類型）與數據說故事技巧。學生完成課程後具備以 Excel 進行完整業務數據分析並以視覺化報告呈現的實務能力，是商學院所有數據分析課程（ISOM2500、ISOM3310）的重要工具先修基礎。

## Course Overview

**Instructor**: Dongwon Lee

Hands-on course focused on Microsoft Office Suite and information systems fundamentals. Emphasizes practical skill-building over theory, using business case scenarios throughout.

## Key Topics

### Spreadsheet Skills (Excel)
- Worksheet navigation; cell references (relative, absolute, mixed)
- Formulas and functions: IF, VLOOKUP, INDEX/MATCH, SUMIF, COUNTIF
- Data validation; named ranges; conditional formatting
- PivotTables and PivotCharts: grouping, filtering, calculated fields
- Charts: bar, line, scatter; formatting for professional presentation
- Solver add-in: linear programming problems in Excel — connection to [[linear-programming]]
- Data Analysis ToolPak: descriptive statistics, regression, t-tests

### Database Skills (Access / SQL basics)
- Relational database concepts: tables, primary keys, foreign keys
- Building queries in Access: SELECT, WHERE, JOIN, GROUP BY
- Forms and reports: data entry interfaces; printed outputs
- Introduction to normalization — see [[database-systems]]

### Information Systems Concepts
- MIS (Management Information Systems): transaction processing, decision support, executive IS
- ERP (Enterprise Resource Planning): modules and integration — see [[erp]]
- CRM systems: customer data management — see [[crm]]
- Cloud computing: SaaS, PaaS, IaaS; business implications
- Cybersecurity basics: phishing, password policies, data governance

### Data Visualization and Presentation
- Principles of effective chart design: minimizing chart junk; appropriate chart types
- PowerPoint: slide design principles; storytelling with data
- Dashboard design: KPI selection; visual hierarchy
